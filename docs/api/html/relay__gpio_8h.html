Detailed Description

relay_t implementation for a relay driven by one digital pin.

Pure C: all pin access goes through the injected pin_hal_t, so the driver runs on the host with a mock HAL. Each relay is verified by reading the pin back after every drive. This checks the pin, not the relay contact.

◆ relay_gpio_create()

relay_err_t relay_gpio_create ( const relay_gpio_config_t * cfg,
const pin_hal_t * hal,
relay_t * out )

Create a GPIO relay and put it in the safe state (OFF).

The OFF level is latched before the pin becomes an output, so the relay never glitches ON at boot. The OFF level is then verified by read-back.

Parameters
cfgPin configuration.
halPin HAL. Copied; hal->ctx must outlive the relay.
outReceives the relay handle on success.
Returns
RELAY_OK; RELAY_ERR_ARG for NULL or invalid arguments; RELAY_ERR_NOMEM; RELAY_ERR_IO if the pin could not be configured; RELAY_ERR_VERIFY if the pin did not read back as OFF.
