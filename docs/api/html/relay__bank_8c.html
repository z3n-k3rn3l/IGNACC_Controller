Detailed Description

Relay bank: index-based and all-at-once operations on relay_t.

Tour stop 2. relay_bank_set_all() is the lower half of ALL_ON / ALL_OFF: it drives every relay back to back and never stops early, so one faulty relay can't leave the others in the wrong state.

◆ relay_bank_set_all()

relay_err_t relay_bank_set_all ( const relay_bank_t * bank,
bool on )

Drive every relay to the same state, back to back.

Every relay is attempted even if an earlier one fails, so one faulty channel can never leave the others in the wrong state. The relays switch microseconds apart; the caller waits one settle delay afterwards.

Parameters
bankThe bank.
ontrue = all ON, false = all OFF.
Returns
RELAY_OK if every relay succeeded, otherwise the first error seen (RELAY_ERR_ARG if bank is NULL).
