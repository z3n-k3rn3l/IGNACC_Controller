Detailed Description

The state machine: parses each line, drives relays, sends replies.

Tour stop 4, the heart of the firmware. Read app_fsm_handle_line() first, then handle_command(), which dispatches to the handlers above it. Every relay failure ends in drive_safe_state() (all relays OFF).

app_fsm_t * app_fsm_create ( const app_fsm_config_t * cfg)

Create an FSM in state APP_FSM_STATE_INIT.

The relay handles are copied, so cfg->relays.relays may be a temporary array. The relays themselves are not touched until app_fsm_start().

Parameters
cfgConfiguration.
Returns
The FSM, or NULL if cfg is invalid (missing link, version, delay or relays; count outside 1..PROTO_MAX_CHANNELS) or memory runs out.
