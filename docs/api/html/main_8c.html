Detailed Description

IGNACC_Controller composition root.

Tour stop 1: start reading the code here.

Reads the Kconfig settings, checks the relay pins at compile time, creates the objects, injects dependencies and starts the tasks. No application logic lives here. Only this file reads sdkconfig; every other module gets plain structs, which is why they can run on a PC with mocks.

◆ app_main()

void app_main ( void )

Firmware entry point (called by ESP-IDF after boot).

Creates and wires everything, in this order:

  1. One relay_gpio per configured channel; each pin is latched OFF before it becomes an output.
  2. The command queue shared by the link (producer) and the FSM (consumer).
  3. The UART link, which returns the link_tx_t used for replies.
  4. The state machine, given the relays, link, version, settle delay and delay function; app_fsm_start() drives every relay OFF.
  5. The FSM task that feeds queued lines to the state machine.

Any failure calls halt(). app_main() then returns; the two tasks run on.
