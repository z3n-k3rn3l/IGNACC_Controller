Detailed Description

Command parser and response formatter (implementation of protocol.h).

Tour stop 5. Fixed commands (ALL_ON, ALL_OFF, HeyU, STATUS) are matched against a table; IN<n>_ON/OFF is parsed by parse_relay(). All formatters go through snprintf and report truncation as -1.

◆ proto_parse()

proto_cmd_t proto_parse ( const char * line,
size_t len )

Parse one received line.

Matching is exact and case-sensitive. Channel numbers are plain decimal without leading zeros: IN1_ON and IN12_OFF are valid, IN01_ON, IN0_ON and IN17_ON are not. Embedded NUL bytes never match.

Parameters
lineReceived bytes, terminator already stripped. Need not be NUL-terminated. May be NULL.
lenNumber of bytes in line.
Returns
The command. kind is PROTO_CMD_NONE for anything that is not a valid command (including a NULL line).
