Detailed Description

Application state machine: the sole owner of the relays.

Pure C. Consumes received lines, drives relays and sends responses through the injected link. All dependencies (relays, link, delay) are injected, so it runs unchanged on the host with mocks, and with any number of relays (1..PROTO_MAX_CHANNELS) of any relay_t implementation.

States: 

*   INIT  --app_fsm_start()-->  READY
*   INIT  : lines are ignored.
*   READY : lines are parsed and executed.
*

Command handling in READY:

  • IN<n>_ON/OFF: drive relay n, wait the settle delay, verify the read-back, reply _OK. A channel the board doesn't have gets UNK_NACK.
  • ALL_ON/OFF: drive every relay, wait one settle delay, verify every read-back, reply _OK.
  • Any failure: reply _FAIL immediately and drive all relays OFF.
  • Anything else: reply UNK_NACK; no relay is touched.

Safety: all relays are driven OFF on start and whenever a relay command fails.
