int(*) pin_hal_ops_t::configure_output(void *ctx, int pin, int initial_level)

Configure a pin as input+output, so its level can be read back.

Contract: initial_level must be latched before the output driver is enabled, so the pin never glitches to the other level.

Parameters
ctxImplementation handle (pin_hal_t::ctx).
pinGPIO number.
initial_levelLevel (0/1) the pin must have when it becomes an output.
Returns
0 on success, non-zero on error.
