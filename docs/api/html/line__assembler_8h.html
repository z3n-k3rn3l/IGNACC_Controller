Detailed Description

Assembles a byte stream into lines.

Pure C.

  • Lines end with '\n'; one trailing '\r' is stripped.
  • Lines longer than max_len (excluding terminators) are discarded entirely, including any command at their end.
  • Empty lines are not emitted.
