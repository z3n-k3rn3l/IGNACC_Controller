Detailed Description

Abstract relay interface: an opaque handle plus a function table.

Every relay implementation (relay_gpio today; an I/O expander or shift register tomorrow) fills in a relay_ops_t and keeps its state behind the opaque ctx pointer. Users (relay_bank, app_fsm) only see this header, so a new implementation never requires changes to them.
