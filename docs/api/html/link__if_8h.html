Detailed Description

Transport-independent contracts shared by the link and the state machine.

Header only, pure C. The link (uart_link) produces link_line_t items and implements link_tx_t; the state machine (app_fsm) consumes lines and sends responses through link_tx_t. Neither knows about the other.

Module: uart_link
