Detailed Description

UART line transport: IDF driver events in, complete lines out.

Tour stop 3. uart_link_start() installs the IDF UART driver and starts uart_link_task(). The task turns UART_DATA events into bytes, bytes into lines (line_assembler) and posts each line to the command queue without ever blocking. Replies go out through uart_link_send(), exposed as a link_tx_t.

◆ uart_link_task()

void uart_link_task ( void * arg)
static

The receive task: waits for UART driver events forever.

  • UART_DATA: read and assemble lines.
  • FIFO overflow / ring buffer full: flush everything and discard the partial line.
  • Frame / parity error: discard the line being received.
