int esp_configure_output ( void * ctx,
int pin,
int initial_level )
static

pin_hal_ops_t::configure_output: latch the level, then enable the output.

gpio_set_level() writes the output register even while the pin is still an input, so the pin comes up at initial_level with no glitch. The pin is configured as input+output so its level can be read back.

Parameters
ctxUnused.
pinGPIO number.
initial_levelLevel to latch before the output is enabled.
Returns
0 on success, -1 on an ESP-IDF error.

◆ pin_hal_esp()

pin_hal_t pin_hal_esp ( void )

The ESP-IDF GPIO HAL instance.

Stateless: ctx is NULL and the same instance can be shared by all relays. configure_output() writes the level before calling gpio_config() with GPIO_MODE_INPUT_OUTPUT, which satisfies the no-glitch contract.

Returns
The HAL instance.
