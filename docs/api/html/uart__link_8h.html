Detailed Description

Line transport over an ESP-IDF UART.

Uses the IDF UART driver (driver-managed ISR, ring buffer and event queue; no custom ISR). A receive task assembles bytes into lines with line_assembler and posts each complete line to the injected queue. Knows nothing about relays or the command set.
